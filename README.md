# timidity (mirror)

Mirror of the **TiMidity++** source tree — the software MIDI synthesizer that converts MIDI files to audio — kept in Robert Pelloni's reference library. This copy exists because, per the upstream note, the original SourceForge project is defunct and this serves as a temporary home for the source code.

The tree is the classic autotools layout (`configure`, `libarc/`, `libunimod/`, `interface/`, `timidity/`). For documentation and project history, see `doc/` and the upstream TiMidity++ project.
